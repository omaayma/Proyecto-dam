NOMBRE DE PROYECTO

Nuestro proyecto final de ciclo tiene como objetivo el desarrollo de una plataforma para la gestión de los talleres de reparación de vehículos. Estará compuesta por un lado, por una aplicación web destinada al personal del taller, y por otro lado, por una aplicación móvil orientada a los clientes. Amabas estarán conectadas a un mismo sistema de backend y base de datos.

Con esta plataforma, pretendemos facilitar la administración de los clientes, vehículos, citas, presupuestos, facturas y control de piezas, permitiendo una gestión más organizada y eficiente del negocio. 
Además, el sistema incorporará funcionalidades como la consulta del estado de las reparaciones, mejorando así la comunicación entre el taller y sus clientes. 

Este proyecto nos permitirá aplicar los conocimientos adquiridos durante el ciclo formativo mediante el uso de tecnologías como Spring Boot, Java y herramientas de automatización como n8n.

- REQUISITOS FUNCIONALES

Nuestro sistema ofrecerá las siguientes funcionalidades a los diferentes tipos de usuarios.
1. Registrar nuevos clientes en la base de datos.
2. Modificar, consultar y eliminar los clientes.
4. Registar vehículos asociados a un cliente en el sistema.
5. Modificar, consultar y eliminar vehículos del sistema.
6. Registrar empleados del taller.
7. Modificar, consultar y eliminar la información de los empleados.
8. Crear citas para la revisión o reparación de vehículos.
9. Modificar, consultar el estado y cancelar las citas existentes.
10. Generar y consultar los presupuestos.
11. Modificar el estado de un presupuesto.
12. Generar facturas a partir de presupuestos aceptados.
13. Consultar las facturas registradas en el sistema.
14. Registrar, modificar y actualizar el stock de piezas del taller.
15. Consultar el inventario de piezas disponibles.

Asimismo, el sistema dispondrá de las siguientes funcionalidades respecto a la aplicación móvil, automatización y notificaciones.

   

- REQUISITOS NO FUNCIONALES
  
Las características técnicas que cumple nuestro sistema son las siguientes:
1. Arquitectura Cliente-Servidor.
2. Base de datos MySQL para el almacenamiento de la información.
3. Backend con Spring Boot y Java.
4. Sistema con roles de usuario(administrador, empleado y cliente).
5. Sistema de autenticación mediante usuario y contraseña.
6. Aplicación web accesible desde navegadores modernos.
7. Aplicación web desarrollada para dispositivos Android.
8. Aplicación web accesible desde el navegador.
9. Comunicación entre aplicaciones mediante API REST.
10. Interfaz de usuario clara e intuitiva para facilitar el uso de la plataforma.
11. Organización del código mediante arquitectura por capas.
12. Automatización de notificaciones y flujos de trabajo mediante n8n.
